# Owner-Critical Keywords for LOA Pink Highlighting

When highlighting rows from an owner/shareholder perspective, match these keyword categories against column A text. Apply `PatternFill(start_color="FFD6E4", end_color="FFD6E4", fill_type="solid")` to the entire row.
