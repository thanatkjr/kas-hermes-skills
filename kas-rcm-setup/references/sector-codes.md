## หมายเหตุสำคัญ

- **UNVS** = กิจกรรมทั่วไป (Universal) — ไม่ใช่ industry แต่รวมอยู่ทุก process เสมอ (292 activities) → เวลาเรียก `get_process_rcm(process, sector)` ระบบจะรวม UNVS ให้อัตโนมัติ
- **GOVT** = ภาครัฐ/ไม่แสวงหากำไร (รวมถึงรัฐวิสาหกิจ หน่วยงานสาธารณะ มูลนิธิ สมาคม)
- **FRAN** = แฟรนไชส์ (cross-sector — ธุรกิจที่ทำได้หลาย industry)
- 28 รหัสแรกอิงจาก SET Industry/Sector Profile ตรงตัว; 3 รหัสท้าย (UNVS/GOVT/FRAN) เป็นหมวดพิเศษที่ KAS เพิ่ม
