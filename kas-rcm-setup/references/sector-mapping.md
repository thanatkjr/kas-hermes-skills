# RCM Sector Codes → ชื่อไทย (31 codes, อิง SET)

> ⚠️ **ไฟล์นี้เป็นไฟล์เก่า** — ชื่อไทย canonical (Admin confirm 2026-08-17) อยู่ที่ `sector-codes.md` ใช้ไฟล์นั้นเป็นหลัก ไฟล์นี้เก็บ detail เรื่อง PERS/FRAN/GOVT + วิธี parse SET ไว้เท่านั้น

ฐานข้อมูล RCM (DB v4) มี **31 sector codes** — ไม่มี tool `list_sectors` ต้อง derive เอง
(เรียก `get_process_overview` ทั้ง 10 processes → extract unique `sector_code`)

ชื่อไทยอ้างอิงจาก **SET (ตลาดหลักทรัพย์)** หน้า Industry/Sector Profile:
`https://www.set.or.th/th/market/index/set/industry-sector-profile`
→ 28 หมวดธุรกิจ + 8 กลุ่มอุตสาหกรรม มีชื่อไทยครบ (แตะ SET ไม่มี 3 ตัว: FRAN / GOVT / UNVS)

## ⚠️ PERS ≠ "Personnel" / บริการบุคคล

`PERS` ใน RCM **ไม่ใช่** บริการบุคคล (Personnel Services) แต่คือ **ยาและเครื่องสำอาง**
(Pharma & Cosmetics — ผลิตภัณฑ์ควบคุม อย. / GMP):

- `OP-PERS-001` การผลิตยาและเครื่องสำอางตามมาตรฐาน GMP
- `P-PERS-001` การจัดซื้อวัตถุดิบและผลิตภัณฑ์ควบคุมตามข้อกำหนดของ อย.
- `R-PERS-001` การขายผลิตภัณฑ์ควบคุม (อย./ใบอนุญาต)
- `HR-PERS-001` การบริหารบุคลากรผลิตยาและเครื่องสำอาง (GMP)

ชื่อไทยที่ถูกต้อง (ตาม Admin confirm): **"ของใช้ส่วนตัวและเวชภัณฑ์"** (= ยา/เครื่องสำอาง อย./GMP) — อย่า map เป็น "บริการบุคคล"

## กำหนดชื่อ FRAN / GOVT จาก activity จริง

- **FRAN** = แฟรนไชส์ — `R-FRAN-001` รับรู้รายได้ค่าธรรมเนียมแรกเข้าแฟรนไชส์, `OP-FRAN-001` ควบคุมมาตรฐานสาขาแฟรนไชส์
- **GOVT** = ภาครัฐ/ราชการ — `P-GOVT-001` จัดซื้อจัดจ้างภาครัฐตาม พ.ร.บ., `AF-GOVT-001` บัญชีภาครัฐ GFMIS, `R-GOVT-001` รับเงินงบประมาณ/เงินอุดหนุน

## 8 กลุ่มอุตสาหกรรม SET (context — RCM ไม่ได้ใช้ layer นี้)

เกษตรและอุตสาหกรรมอาหาร · สินค้าอุปโภคบริโภค · ธุรกิจการเงิน · สินค้าอุตสาหกรรม ·
อสังหาริมทรัพย์และก่อสร้าง · ทรัพยากร · บริการ · เทคโนโลยี

## วิธี re-derive / parse หน้า SET (ถ้าต้องการอัปเดต)

หน้าเป็น Nuxt.js (`window.__NUXT__` payload) — มีตาราง sector ที่จับคู่ code + ชื่อไทย
ใน `<tr>` เดียวกัน:

```
<span style="font-size: 1.25rem;">CODE</span>  ...  <span ...font-size: 0.875rem;">ชื่อไทย</span>
```

regex: `1\.25rem;\">([A-Z&]{2,10})</span>` (ช่วง {2,10} ต้องครอบ FASHION/TOURISM = 7 ตัว
และ PF&REIT ที่มี `&`) แล้วจับคู่กับ `font-size: 0\.875rem;\">([^<]+)</span>` ภายใน row เดียวกัน
